# pascal-lazarus-devdocs

[FreePascal](https://www.freepascal.org/) and
[Lazarus](https://www.lazarus-ide.org/) tutorials, articles, and practical guides for building clean, 
fast, native apps with LCL as the core cross-platform GUI framework for Linux, Windows, and macOS.

In this repository, I explore Lazarus and the LCL (Lazarus Component Library) as a 
lightweight, reliable "Win32-equivalent" / common core platform for modern native 
desktop app development without heavy runtime stacks or a complex learning curve.

## Repository Structure
* *docs* - Will contain articles, references, comparison maybe with Win32 API / .NET (Windows.Forms).
* *examples* - Example apps to serve as starting points, hopefully thoroughly commented to serve as starting points for others.

## Getting Started
To compile and run the examples in this repository, you will need to install the Lazarus IDE.

# Clone the repository
```bash
git clone https://github.com/ihladni/pascal-lazarus-devdocs.git
```
